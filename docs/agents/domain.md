# Domain Docs

MinBack is a single-context repository.

Before implementation, read in order:

1. `CONTEXT.md`
2. `docs/brief.md`
3. `docs/team/engineering-rules.md`
4. The relevant Dev assignment
5. `docs/team/dev-a-tasks.md` when working on Dev A scope

`CONTEXT.md` is the only domain summary. This directory must not contain another domain summary. Read relevant files under `docs/adr/` if that directory is introduced later.
